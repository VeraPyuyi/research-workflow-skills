# ACL discovery tranche: presentation synthesis

Exactly 12 manifest-listed papers: nine selected, three controls. These are purposive genre/domain comparators, not groups matched for measured length or quality. Labels are not quality guarantees, and this tranche cannot establish an award recipe or causal effect of presentation. Observations concern exposition, not scientific proof, novelty or reproduced results.

- **Make the argument navigable.** GeoRA (acl-2026-1, pp3-5) connects architecture/masking to grouped evaluations; CAR-bench (acl-2026-3, pp2,7) separates system components and evaluation dimensions. STEER (acl-2026-4, pp4-6) repeats mechanism/evidence/limitation units. Transfer this structure when each proposed component has a corresponding observable test; a roadmap alone supplies no evidence.
- **Explain one inspectable unit before abstraction.** CausalGym (acl-2024-1, p3) aligns original templates with generated minimal pairs. Prompting theory (acl-2025-1, p5) uses a toy distribution to explain ranking reversal. The control 500xCompressor (acl-2025-5, p2) aligns pretraining, fine-tuning and prediction panels. Repeated entities and stage labels reduce translation between prose, equations and figures.
- **Display interpretations alongside their limits.** The Social World Models control (acl-2026-5, p8, Figure3) separates hypothetical predictions from observed contrasts and retains a counterexample. PsySafe (acl-2024-3, p6) shows overlapping score distributions; its p9 limitations acknowledge unsafe behavior despite safe scores. Distributional association should not silently become a mental-state or causal explanation. STEER's independent-logit assumption likewise constrains its theory-to-design narrative.
- **Put comparability where readers use results.** OWSM-CTC, another control (acl-2024-5, p6), explains data/decoding caveats and marks reference rows. CausalGym's p6 table separates raw efficacy from selectivity, changing the apparent winner. Mapping models (acl-2025-2, appendix p41) contrasts grouped and random folds. Prompting theory (pp8-9) distinguishes oracle potential from achieved performance. These moves transfer only with explicit budgets, access assumptions and evaluation units.
- **Preserve losses and non-results.** GeoRA's baseline retains some task wins; CAL (acl-2024-2, p7) loses MNLI accuracy in one few-shot comparison; 500xCompressor's relative gains coexist with substantial absolute information loss. IndicSynth (acl-2025-3, p6) exposes weak Sanskrit results and missing classifier coverage. Its embedding overlap/detector behavior cannot alone establish linguistic authenticity or downstream training value. OWSM's repetition-free appendix example still mistranslates (p18).
- **Treat readability as evidence access.** Clear legends, aligned cases and repeated metric blocks help inspection in both groups. Tiny heatmap labels, faint reference rows, dense appendix grids and unexplained cluster axes impede it. Captions should define encodings, aggregation, uncertainty and exclusions; visible p-values or agent-score dispersion should not be mistaken for complete uncertainty reporting.

# Compact Handoff Example

This is a synthetic example of the required information, not project evidence or
a mandated directory layout.

**Artifacts:** protocol P3; run manifest R12; analysis A4.

**Evidence:** all six completed attempts under P3, paired by seed; the calculation
is recorded in A4. One still-active job J7 is recorded separately and excluded from
the completed-run aggregate with its current status.

**Status:** analysis complete for the available attempts; the research conclusion
is ready for review. No additional run or external action was performed.

**Open issues:** the estimate is imprecise. J7's current consumption is unknown.
The budget permits no new launch until its status and committed usage are reconciled.

**Next step:** consolidate the limited claim at the applicable evidence milestone;
use startup delegation if it covers conclusion formation, otherwise present the
user's decision package. Route
job reconciliation to research-experiment with J7 and the existing budget record;
do not rerun J7 while its status is unknown.

**Dispatch:** a free executor drafted the synthesis; a model of a different
lineage independently checked the stated assumptions. Requested and served models
are recorded separately. The milestone reviewer is unexecuted because this worker
could not dispatch it, so the claim is not treated as independently verified.

If the user asks only for a paper reading, use the same fields for the reading
artifact and available source excerpt; a project manifest is unnecessary.

For a manuscript round, the same handoff can link a compact resume snapshot:

- Round I5; definitions D2, protocol P3, analysis A4, manuscript M6.
- Claim K8 at M6/Discussion: unresolved explanation, supported observation;
  gap is an unmeasured mediator, next check belongs to design.
- Source S4/v2, equation 7 inspected; bibliography resolved, applicability limited
  by an unmet independence assumption.
- Finding F2: confirmed denominator mismatch, repaired in M6/table 2;
  recheck of aggregation and dependent abstract text remains unexecuted.
- Approval U3 covers P3 and its original allowance; J7 still has unknown
  committed consumption. No new job can be launched from this snapshot alone.

These entries are invented examples, not executed branch or review records.

For a full-paper Goal, add a compact continuation line:

- Goal binding G1; startup U1 delegates in-scope protocol/conclusion revisions.
- Completion: venue-specific final paper and reproduction package, two fresh reviews.
- M3 pending on analysis A4; M1/M2 coverage remains valid for unchanged dependencies.
- Venue V2 distinguishes submission requirements and optional post-acceptance artifacts.
- M4/M5 reviewers are scheduled, not executed; no finished-paper claim is warranted.
- A completed analysis hands off to evidence review/writing rather than completing G1.
- Stage status: analysis A4 complete; paper status: incomplete; native G1 active.
- Next action: writing branch W2 started from reviewed claims K1-K7. J7 status
  reconciliation is separate; it does not prevent drafting those supported claims.
- On the next host continuation, resume W2/J7 from their records. Do not rerun R12
  or ask for another "continue" merely because analysis A4 finished.

Keep these coordinator records out of the M4/M5 blind reviewer input bundles.

For a project main-line handoff, add a compact reminder:

- Theme E1: preserve facts/relations while ignoring retrieval-irrelevant paraphrases.
- Thesis T3: test a boundary of subspace retrieval at matched capacity and budget.
- Alignment: in-theme-pivot from T2's benefit hypothesis; inspect old T1/T2 as well.
- Task: grouped bootstrap -> source-dependent retrieval scores -> uncertainty
  for claim K3. Supporting analysis, not a new statistics-software paper.
- Return: one bounded existing-data analysis, then main evidence synthesis.
- Provenance: actual original instruction and later decision references; missing
  original material stays a gap, not an invented confirmation.

These are synthetic illustrations. A negative direction is not a measured result;
the evidence ledger determines whether the observation or mechanism is established.

For a workflow release, optimizer event or Jev comparison, add the matching
compact line instead of a new section:

- Candidate release `research-<id>` and digest inspected; adoption is held because
  one customized local copy conflicts. Running jobs J7 and R12 keep their pinned
  protocol/code versions. Independent authorized research continues.
- Stage `research-survey` R2/S3 appended one retrospective event (tag
  `literature-citation`, trace `research/literature.jsonl`); nothing else was triggered.
- Jev decision D1 was advisory only; evidence decided the choice. Unknown billing
  coverage meant no call, so the Jev comparison is recorded as unexecuted.
